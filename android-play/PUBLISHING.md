# Публикация «Угомони кота» в Google Play

Модель продаж: одно приложение, уровни 1–2 бесплатные, разовая покупка `unlock_full`
открывает уровни 3–8 навсегда. В вебе (без Android-обёртки) игра открыта полностью.

## Что лежит в репозитории

| Путь | Что это |
|---|---|
| `index.html` | Игра. Единственный источник, правки делаются только в нём |
| `android-play/` | Проект Android Studio (Gradle, AGP 9.4, compile/target SDK 36, minSdk 24, Play Billing 9.1) |
| `android-play/tools/prepare_assets.py` | Копирует `index.html` в `app/src/main/assets` и встраивает шрифты (игра работает без интернета) |
| `android-play/store/` | Иконка 512, баннеры 1024×500 (en/ru), по 8 скриншотов 1920×1080 (en/ru), тексты описаний |
| `docs/privacy.html` | Политика конфиденциальности (en + ru) |
| `android/` | Старая сборка APK без Gradle, для Play не подходит (нет AAB и биллинга) |

## Как устроена покупка

* `StoreBridge.java` подключает Play Billing и отдаёт игре объект `window.UgomoniStore`
  с методами `buy()`, `restore()` и `refresh()`.
* Ответы приходят в `window.ugomoniStore`: `onPrice('$1.99')`, `onOwned(true/false)`, `onPending()`, `onError(...)`.
* Цену в нужной валюте показывает Google, в коде она не зашита.
* Покупка подтверждается (`acknowledge`) сразу; без этого Google возвращает деньги через 3 дня.
* Покупка проверяется при каждом запуске и возврате в приложение, поэтому:
  * переустановка сохраняет полную версию;
  * при возврате денег уровни снова закрываются.
* Кнопка «Назад» закрывает окно покупки, ставит игру на паузу или сворачивает приложение из главного меню.

## Шаги

### 1. Аккаунт разработчика
1. Зарегистрироваться на https://play.google.com/console (взнос $25, понадобится документ для проверки личности).
2. В **Настройки → Платёжный профиль** создать профиль продавца (merchant). Без него платный товар не создать.
   Нужен банковский счёт, поддерживаемый Google Payments.
3. Для новых личных аккаунтов есть правило: перед выходом в продакшен нужно закрытое тестирование
   **минимум 12 тестировщиков в течение 14 дней подряд**. Тестировщиков (друзья, родные) лучше найти заранее.

### 2. Собрать AAB
Готовый подписанный файл уже лежит в репозитории: [`dist/hush-the-cat-v38.aab`](../dist/hush-the-cat-v38.aab)
(versionCode 30, versionName 1.1). Он подписан ключом загрузки `upload-key.jks`, который передан отдельно и в git не попадает.
Сертификат ключа загрузки: SHA-256 `5c:02:25:59:1f:00:40:23:eb:ab:57:23:52:98:08:07:bc:28:a0:7e:0a:ce:ca:b6:73:c2:9a:74:1c:1d:ea:d5`.
Для следующих версий нужен этот же ключ (положить `upload-key.jks` и `keystore.properties` в `android-play/`).
Если ключ потеряется, его можно сбросить через Play Console (Setup → App signing → Request upload key reset).

Собрать самому:
1. Установить Android Studio (свежую), открыть папку `android-play/`. Студия сама скачает Gradle 9.6.1, AGP и SDK 36.
2. После каждого изменения игры: `python3 android-play/tools/prepare_assets.py` (или `py` на Windows).
3. Создать ключ загрузки: **Build → Generate Signed App Bundle → Create new…**
   * Файл, например, `android-play/upload-key.jks`.
   * Можно заполнить `keystore.properties` по образцу `keystore.properties.example`, тогда `./gradlew bundleRelease` подписывает сам.
   * **Ключ и пароли хранить в надёжном месте и не коммитить** (они уже в `.gitignore`).
4. Результат: `app/build/outputs/bundle/release/app-release.aab`.
5. При каждом следующем обновлении увеличивать `versionCode` в `app/build.gradle.kts`.

### 3. Создать приложение в Play Console
* Название: **Hush the Cat**. Язык по умолчанию: English (United States).
* Тип: Игра, Бесплатное (покупка внутри приложения не делает его платным).
* В **Play App Signing** оставить ключ подписи у Google (по умолчанию). Наш `upload-key.jks` нужен только для загрузки.

### 4. Товар `unlock_full`
Для создания товара нужно хотя бы раз загрузить AAB с биллингом в любой трек (подойдёт внутреннее тестирование).

**Монетизация → Товары → Встроенные товары → Создать**
* ID: `unlock_full` (ровно так, он прописан в коде);
* название: «Full version» / «Полная версия»;
* цена: $1.99 (Google сам пересчитает для других стран; для РФ Play-платежи сейчас недоступны);
* активировать.

### 5. Описание в магазине (Store listing)
* Тексты: `store/listing-en.md` (основной) и `store/listing-ru.md` (добавить перевод ru-RU).
* Иконка 512×512: `store/icon-512.png`.
* Баннер 1024×500: `store/feature-graphic-en.png`, для русского перевода `feature-graphic-ru.png`.
* Скриншоты телефона: `store/screenshots-en/1..8.png` и `store/screenshots-ru/1..8.png` (1920×1080, 16:9).
  Для планшетов можно загрузить те же.
* Категория: Игры → Казуальные (или Аркады). Контактный email обязателен.

### 6. Политика конфиденциальности
1. В `docs/privacy.html` заменить `CONTACT_EMAIL` на рабочий адрес.
2. Включить GitHub Pages: репозиторий → **Settings → Pages → Deploy from a branch → `main` / `/docs`**.
3. Ссылка будет `https://alexandercbgm.github.io/cats_are_assholes/privacy.html`; её указать в Play Console.

### 7. Анкеты в Play Console (раздел «Контент приложения»)
* **Безопасность данных**:
  * приложение данные не собирает и не передаёт;
  * шифрование при передаче: не применимо;
  * удаление данных: не применимо (аккаунтов нет).
  * Оплату обрабатывает Google Play, её отдельно декларировать не нужно.
* **Возрастной рейтинг (IARC)**: мультяшное насилие, без крови и без грубой лексики. Ожидаемо PEGI 7 / ESRB Everyone 10+.
* **Целевая аудитория**: 13+ (если отметить детей до 13, включатся требования программы Families).
* **Реклама**: нет. **Доступ к приложению**: всё доступно без входа.
* **Новости / госприложение / финансы / здоровье**: нет.

### 8. Тестирование и выпуск
1. **Внутреннее тестирование**:
   * загрузить AAB;
   * добавить свой Google-аккаунт в тестировщики и в **Настройки → Тестирование лицензий**;
   * покупки с этого аккаунта бесплатные и тестовые.
   * Проверить: цена на кнопке, покупка, «Восстановить покупку», переустановка, кнопка «Назад».
2. **Закрытое тестирование**: 12+ тестировщиков, 14 дней. Затем подать заявку на продакшен (вопросы о тесте в консоли).
3. **Продакшен**: выбрать страны, отправить на проверку (обычно от нескольких часов до нескольких дней).

## Деньги
Комиссия Google на первый $1 млн дохода в год: 15%. С $1.99 вы получаете примерно $1.69 минус налоги страны покупателя.

## На заметку
Репозиторий публичный, поэтому полная веб-версия игры (`index.html`) доступна любому бесплатно.
Если это важно, репозиторий можно сделать приватным, а политику конфиденциальности разместить в другом месте
(например, Google Sites). GitHub Pages для приватных репозиториев требует платного тарифа.
