# Угомони кота

Мультяшная браузерная игра в духе Moorhuhn про наглых домашних котов. Сейчас это тестовая версия с одним уровнем.

**Уровень 1 — спальня, 3:00 ночи.** Кот орёт, и у вас уходит сон. Нужно довести его «наглость» до нуля, пока не зазвонил будильник и пока кот не исцарапал вас до травмпункта.

## Запуск

Откройте `index.html` в браузере. Сборка не нужна: вся игра — один файл с canvas 2D, звук синтезируется через Web Audio.

## Механики

- **Снаряды** летят по дуге:
  - тапок — сильный удар, оглушает;
  - теннисный мяч — слабый, прыгучий;
  - полотенце — кот в нём запутывается;
  - подушка — придавливает и отбрасывает кота;
  - книга — тяжёлая, оглушает (появляется, когда книги падают с полки);
  - штора — кот запутывается надолго (появляется, когда штора падает).
- **Попадание в голову** даёт ×1,5 урона. Серия попаданий подряд увеличивает множитель очков.
- **Наглость кота** восстанавливается, пока кот не оглушён.
- **Подбор снарядов и аптечек** — кликом. Рядом с бодрым котом подбирать опасно: он поцарапает.
- **Атака кота.** Он приседает (над головой «!») и прыгает в лицо. На экране остаются следы когтей, у вас отнимается здоровье. Если попасть в кота во время подготовки, атака сорвётся.
- **Лечение:** пластырь, подорожник, зелёнка, бинт, аптечка.
- **Разрушаемая комната:** ваза, книги, стакан, лампа, картина, настенные часы, фикус, ноутбук, стекло окна. Мебель копит вмятины и ломается: шкаф распахивается, у тумбочки и стола выпадают ящики, полка обрушивается, шторы срываются, гардина падает. Ущерб в рублях вычитается из итога.
- **Открытая створка окна:** всё, что улетит в правую половину окна, пропадает навсегда. Кончились снаряды — проигрыш.
- **Коты** (выбор по кругу стрелками в меню):
  1. Люцифер — чёрный бесоёб;
  2. Барон Булкин — британец, кот-батон;
  3. Сирена — сиамская истеричка;
  4. Бигфут — мейн-кун, рысь-переросток;
  5. Доби — сфинкс, лысый домовой;
  6. Турбо — бенгальская, мини-леопард;
  7. Апельсин — рыжий, «одна извилина».

  У каждого своя комплекция, окрас, глаза, скорость, регенерация, агрессия и громкость.
- **Победа:** кот падает в нокаут на спину или на бок — крестики в глазах, язык наружу, «zzz».

## Управление

| Действие | Клавиша |
|---|---|
| Бросить / подобрать | клик |
| Выбор снаряда | 1–6 |
| Лечиться | H |
| Пауза | P / Esc |
